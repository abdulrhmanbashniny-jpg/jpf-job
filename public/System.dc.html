🏗️ الطبقات الهندسية الأربع للمنصة

1. طبقة العرض والهوية (Presentation Layer — RTL) HTML5 + CSS3 + Vanilla JS

بوابة المتقدمين (6 شاشات) + لوحة اللجنة (8 شاشات) بهوية لونية مستوحاة من قطاع الدهانات، مع متتبع نزاهة حي للجلسة.

2. طبقة الخادم والـ API (Application Layer) Node.js 20 + Express + Multer

مسارات RESTful محمية بمحدد طلبات (Rate Limiter)، معالجة رفع السير الذاتية، وإخفاء الإجابات النموذجية عن واجهة المتقدم.

3. طبقة التقييم الهجين والفحص الأعمى (AI & Rubric Layer) OpenAI / Gemini / Claude / SmartRubric

طمس البيانات الشخصية (PII Anonymization) قبل إرسالها لمزود الذكاء الاصطناعي، مع محرك دلالي وحسابي مدمج عالي الاعتمادية.

4. طبقة البيانات والحوكمة (Persistence Layer) PostgreSQL 17 + Triggers + Docker

قيود مرجعية صارمة، أعمدة محسوبة تلقائياً، ومحفزات تعيد حساب وزن (40% AI + 60% لجنة) داخل قاعدة البيانات مباشرة.
