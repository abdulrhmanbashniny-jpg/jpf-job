# 🎨 منصة رُواء للتوظيف الذكي (Smart Recruitment Platform)

منصة توظيف ذكية متكاملة وجاهزة للإنتاج الفعلي (**Production-Ready Full-Stack ATS**)، مصممة خصيصاً لقطاعات الصناعات الإبداعية، الدهانات والطلاءات، والكفاءات الهندسية والتجارية. تجمع المنصة بين **الفرز العادل بتقنية الفحص الأعمى (Blind AI Screening)**، **اختبار الجدارة التفاعلي مع تتبع النزاهة**، و**تقييم لجنة التوظيف الموزون (40% ذكاء اصطناعي + 60% لجنة)**، مع نظام **جدولة ذكية للمقابلات (Google Meet)** و**طابور رسائل واتساب هجين (`wa.me`)** بدون أي تكلفة اشتراك شهرية في WhatsApp Business API.

---

## 1. الرؤية الهندسية والمزايا التنافسية للمنصة

1. **فرز موضوعي خالٍ من التحيز (Blind AI Screening):** يقوم الخادم تلقائياً بطمس بيانات الهوية الشخصية (الاسم، البريد الإلكتروني، رقم الجوال) واستبدالها برمز مشفّر (`CAND-BLIND-XXXX`) قبل إرسال البيانات لمحرك التحليل.
2. **اختبار جدارة تفاعلي من 10 أسئلة لكل وظيفة:** يدعم 4 أنماط عملية (اختيار من متعدد، مسائل حسابية هندسية/مالية، مواقف ميدانية نصية، وإرفاق نماذج أعمال)، مع عداد زمني تنازلي ورصد حي لمغادرة التبويب ومحاولات اللصق.
3. **إخفاء الإجابات النموذجية أمنياً على الخادم:** لا تُرسل الإجابات الصحيحة (`correct_option` / `correct_number`) إلى متصفح المتقدم مطلقاً، ويتم التصحيح حصرياً على الخادم.
4. **مفاضلة معيارية موزونة بمحفزات PostgreSQL:** يحسب محفز قاعدة البيانات (`Trigger`) تلقائياً متوسط تقييمات أعضاء اللجنة بالمعايير الخمسة ويدمجه مع درجة الذكاء الاصطناعي وفق معادلة موزونة قابلة للتخصيص (`40% AI + 60% لجنة`).
5. **جدولة تلقائية تراعي بيئة العمل المحلية:** توزيع تلقائي للمواعيد على المرشحين المؤهلين مع فترات استراحة فاصلة، **واستثناء تلقائي لوقت صلاة الظهر (12:00 - 12:45)**، وتوليد فوري لروابط قاعات Google Meet.
6. **طابور واتساب هجين (`wa.me`):** يولّد روابط محادثة مسبقة التعبئة جاهزة للإرسال من رقم المنسق مباشرة مع تتبع حالة كل دعوة (`queued` ← `sent` ← `confirmed`).
7. **أمان كامل للمفاتيح الحساسة:** لا يُحفظ أي مفتاح سري أو بيانات حساسة في المتصفح (`localStorage`/`sessionStorage`) أو في كود الواجهة؛ تُدار كافة الاتصالات والمفاتيح عبر متغيرات البيئة (`.env`) على الخادم فقط.

## 2. الهوية البصرية ونظام التصميم (Design System)

استُلهمت الهوية اللونية من **طيف الأصباغ الترابية والدهانات المعمارية والكفاءات الهندسية** لتمنح انطباعاً دافئاً، منظماً، واحترافياً بعيداً عن القوالب الباردة التقليدية:

| العنصر اللوني | الكود اللوني (Hex) | الاستخدام الوظيفي في الواجهات |
| :--- | :---: | :--- |
| **الأسود الفحمي الداكن (Charcoal)** | `#17191C` | الشريط الجانبي للجنة التوظيف، الهيدر العلوي، الأزرار الرئيسية، ومنصة المركز الأول |
| **التيراكوتا / الطوبي (Terracotta)** | `#C8553D` | أزرار التركيز والإجراءات الحاسمة، التنبيهات، وشارة قسم الإنتاج |
| **الزعفراني الذهبي (Saffron)** | `#E0A21B` | الإشعارات، التمييز البصري، تتويج المركز الأول، وشارة قسم المبيعات |
| **الأخضر الزيتي (Olive Pigment)** | `#2F5D50` | حالات النجاح واجتياز الاختبار (`≥60%`)، تأكيد المقابلات، وشارة قسم الجودة |
| **الرمادي الترابي الدافئ (Warm Sand)** | `#F5F2EC` / `#F3F1EC` | الخلفيات العامة للصفحات والبطاقات الفرعية المريحة للعين |

### الخطوط المعتمدة (Typography — RTL):
* **`Alexandria`**: للترويسات، العناوين الكبرى، والأقسام الترحيبية.
* **`IBM Plex Sans Arabic`**: للنصوص الأساسية، الجداول، وحقول النماذج لوضوح قرائي عالٍ.
* **`IBM Plex Mono`**: للأكواد الوظيفية (`SL-204`, `PT-101`)، الأرقام المرجعية (`APP-2026-1001`)، النسب المئوية، والمؤقت الزمني.

## 4. هندسة قاعدة البيانات (`smart_hr_db` — PostgreSQL)

يضم الملف `database/schema_and_seed.sql` تسعة جداول مترابطة بقيود مرجعية صارمة:
1. **`jobs`**: بيانات الوظائف، برومنت الـ AI، درجة الاجتياز، ومصفوفة الأسئلة الـ 10 (`JSONB`).
2. **`candidates`**: سجل موحد للمتقدمين مع قيود عدم تكرار (`UNIQUE` على البريد والجوال).
3. **`applications`**: الطلبات، الدرجات التحليلية، مؤشرات النزاهة، وقيد `UNIQUE (job_id, candidate_id)` لمنع التقديم المكرر لنفس الوظيفة.
4. **`assessment_answers`**: الإجابات التفصيلية المصححة لكل سؤال ومرفقات الأعمال.
5. **`committee_evaluations`**: تقييمات أعضاء اللجنة بـ 5 معايير موزونة مع عمود محسوب تلقائياً (`GENERATED ALWAYS AS`) ومحفز `trg_committee_eval_sync`.
6. **`interviews`**: مواعيد المقابلات، روابط Google Meet، وحالات التأكيد.
7. **`wa_messages`**: طابور رسائل واتساب الهجينة وروابط `wa.me` الجاهزة.
8. **`system_settings`**: إعدادات الأوزان، الجدولة، المزودات، والقوالب.
9. **`audit_logs`**: سجل الحوكمة والتدقيق الكامل لكافة العمليات.

**البيانات التأسيسية المدمجة (Seed Data):**
تأتي قاعدة البيانات مجهزة بـ **5 وظائف تخصصية كاملة** على رأسها وظيفة **مندوب مبيعات حلول الدهانات المعمارية والصناعية (`SL-204`)**، و**6 مرشحين واقعيين** على رأسهم المرشحة **سارة بنت عبدالله الغامدي (`APP-2026-1001`)** بكامل إجاباتها العشر وتقييم اللجنة ومقابلتها المجدولة.

## 5. دليل الترقية والإعداد على خادم الإنتاج (Ollama + النطاق الرسمي + الصلاحيات RBAC)

### أولاً: النشر أو الترقية بضغطة واحدة على الخادم (`Ubuntu 24.04 VPS`)
```bash
cd /opt/jpf-job && git pull origin main && bash deploy-vps.sh
```
*سيقوم السكريبت بتحديث الحاويات دون المساس ببيانات قاعدة البيانات، وتفعيل جدول الصلاحيات (`staff_users`) تلقائياً، وطباعة بيانات دخول المدير العام (`admin`).*

### ثانياً: ربط موديلات Ollama الخاصة بك على الخادم (مجاني ومحلي 100%)
```bash
sudo bash /opt/jpf-job/setup-ollama-bridge.sh qwen2.5:7b
```
ثم ادخل إلى لوحة اللجنة (`Settings.dc.html`) ← اختر **Ollama Local LLM** ← اضغط **جلب الموديلات المثبتة** ← **حفظ**.

### ثالثاً: ربط النطاق الرسمي (Custom Domain) مع شهادة HTTPS تلقائية
وجّه سجل `A Record` لنطاقك إلى عنوان IP الخادم، ثم نفّذ أمراً واحداً فقط:
```bash
sudo bash /opt/jpf-job/setup-domain.sh jobs.yourdomain.com admin@yourdomain.com
```
*يقوم السكريبت تلقائياً بتثبيت Nginx، ضبط حجم رفع السير الذاتية (15MB) ومهلة استجابة Ollama (120s)، قفل منفذ 3000 على `127.0.0.1`، وإصدار شهادة SSL رسمية من Let's Encrypt.*

### رابعاً: نظام الصلاحيات وحسابات اللجنة (`RBAC`)
جميع شاشات اللجنة (`Dashboard`, `CandidateProfile`, `Ranking`, `Scheduler`, `Interviews`, `JobBuilder`, `Settings`, `Users`, `System`) ومجلد السير الذاتية (`/uploads/*`) محمية بالكامل على مستوى الخادم بجلسات `HttpOnly` مشفرة:
* **`super_admin` (مدير النظام):** كامل الصلاحيات + إدارة حسابات الأعضاء (`Users.dc.html`) + إعدادات Ollama والأوزان.
* **`committee_member` (عضو لجنة التوظيف):** استعراض ملفات المتقدمين وإدخال التقييم المعياري (1-5).
* **`hr_coordinator` (منسق الموارد البشرية):** إدارة الوظائف والأسئلة، الجدولة الذكية، وطابور رسائل واتساب.

## 6. ملخص مسارات الواجهة البرمجية (REST API Reference)

| المسار (Endpoint) | الطريقة | الوظيفة |
| :--- | :---: | :--- |
| `/api/health` | `GET` | فحص جاهزية الخادم وزمن استجابة PostgreSQL وحالة مزودي الذكاء الاصطناعي |
| `/api/jobs` | `GET` / `POST` | جلب الوظائف المتاحة (مع حجب الإجابات عن المتقدم) أو إنشاء وظيفة جديدة |
| `/api/jobs/:idOrCode` | `GET` / `PUT` | جلب تفاصيل وظيفة محددة أو تحديث إعداداتها وبرومنت AI |
| `/api/applications` | `POST` / `GET` | تسجيل طلب جديد ورفع السيرة الذاتية (PDF/DOCX) ومنع التكرار، أو استعراض الطلبات |
| `/api/assessments/submit` | `POST` | تصحيح الأسئلة الـ 10، حساب النزاهة ومطابقة السيرة، وإصدار التقرير والنتيجة الفورية |
| `/api/stats` | `GET` | مؤشرات الأداء الرئيسية (KPIs)، الحركة اليومية، ومسار التوظيف (Funnel) |
| `/api/evaluations` | `POST` | حفظ تقييم عضو اللجنة بالمعايير الخمسة وتحديث الدرجة الموزونة تلقائياً |
| `/api/ranking` | `GET` | جلب ترتيب المرشحين وفق المعادلة الموزونة (40% ذكاء اصطناعي + 60% لجنة) |
| `/api/interviews/auto-schedule` | `POST` | الجدولة الذكية التلقائية مع استثناء صلاة الظهر وتوليد قاعات Google Meet |
| `/api/wa-messages` | `GET` / `PATCH` | إدارة طابور رسائل واتساب الهجينة (`wa.me`) وتحديث حالات الإرسال والتأكيد |
| `/api/settings` | `GET` / `PUT` | إدارة إعدادات النظام وقوالب الرسائل دون تخزين أي مفاتيح سرية في المتصفح |
